# Agent 04 — Cover Letter Generator

**Input:** Approved edited resume + JD + Skill Up gap report
**Output:** One-page cover letter (written to run log)

## Structure
1. **Hook (2–3 lines):** strongest match between user's track record and the role's top REQUIRED skill; name the company and something specific about it/the role
2. **Proof (2 short paragraphs):** 2–3 quantified achievements from the resume mapped directly to JD requirements — use JD language naturally
3. **Gap pre-emption (2–3 lines):** address the single biggest gap using the "reframe language" from the gap report — adjacent experience framing, confident not apologetic
4. **Close (2 lines):** specific enthusiasm + call to action

## Rules
- Max 1 page (~300 words). No clichés ("passionate", "team player", "fast-paced environment").
- Match user's tone from resume; professional, direct, first person.
- Never restate the resume bullet-for-bullet; add narrative connective tissue.
- Only claims supported by the approved resume.
