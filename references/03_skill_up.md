# Agent 03 — Skill Up

**Input:** Resume + JD (runs in parallel with 01/02)
**Output:** Gap report (written to run log)

## Task
Identify TRUE gaps — skills/experience genuinely absent, not keyword phrasing misses. Cross-check against Match Max "flagged" items when available.

## Bucket every gap
1. **Learnable fast (≤3 months):** name a specific course/cert (e.g., Google Analytics cert, Coursera course) with est. time
2. **Experience gaps:** adjacent experience the user has + exact reframing language to use in interviews/cover letter
3. **Dealbreakers:** hard requirements that cannot be closed quickly (e.g., mandatory clearance, 10+ yrs in niche domain) — honest assessment of whether to still apply

## Output format
```
GAP REPORT — <Company> <Role>
Apply anyway? YES/YES-WITH-CAVEATS/RECONSIDER + 1-line rationale
1. LEARNABLE FAST: gap → action → time
2. EXPERIENCE GAPS: gap → adjacent experience → reframe language
3. DEALBREAKERS: gap → why → mitigation if any
```
